# Agent Board 0.2.6

- Streaming keeps your reading position, code scroll and copy-button focus.
- Fixed stale tool steps, unread labels and session grouping.
- Improved small-window layouts, question forms and light-theme contrast.
- Added keyboard navigation and reduced-motion support.
- Clearer offline feedback and protection against duplicate session starts.

Offline checks and isolated UI tests passed. Live provider and in-game checks
remain unverified for this release.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/btsouth/agent-board/v0.2.6/install.sh | bash
```

Existing installs can run `agent-board update`.

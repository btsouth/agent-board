# Agent Board 0.2.2

The board now puts what matters on top:

1. **Needs you**: only approvals and questions an agent is blocked on.
2. **Running**
3. **Just finished**: anything that ended in the last half hour, plus unread
   replies and failures from the last three hours.
4. **Earlier**: everything else, dimmed.

Failures and old unread replies no longer sit in Needs you. The badge counts
recently finished work too.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/btsouth/agent-board/v0.2.2/install.sh | bash
```

Existing installs can run `agent-board update`.

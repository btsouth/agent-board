# Agent Board 0.2.0

This release is about talking to your agents from the overlay, not just
watching them.

![Agent Board overlay with fictional sessions](https://raw.githubusercontent.com/btsouth/agent-board/v0.2.0/docs/art/overlay-board.png)

## What's new

- Sessions are grouped by what they need from you: Needs you, Running, New
  replies and Seen.
- Replies render Markdown, with code blocks you can copy, tables and links.
- Tool calls show up between messages as a short expandable list of steps.
- Hermes replies stream while they are being written, and T3 Code replies
  arrive as fast as T3 Code shows them.
- Settle T3 Code threads and archive Hermes sessions from the board, or press
  `E`.
- Read state follows T3 Code's settled threads and Hermes's own read marker.
- The badge is smaller, draggable, counts new replies and pulses when something
  new needs you.
- The board is bigger by default and remembers its size.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/btsouth/agent-board/v0.2.0/install.sh | bash
```

Start World of Warcraft in Windowed or Windowed Fullscreen mode. The badge
appears when the game starts; click it or press `Super+Alt+C` to open the
board. Existing installs can run `agent-board update`.

## Notes

- Linux with systemd user services is the tested bridge host.
- T3 Code support needs Node.js 24 or newer.
- Hermes streaming and Stop need the Hermes desktop backend running. Without it,
  replies still go out through the Hermes CLI.
- T3 Code releases text a paragraph at a time by default. Set
  `"responseStreamingMode": "token"` in T3 Code's settings for token-by-token
  text in both T3 Code and the overlay.

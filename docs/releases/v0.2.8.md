# Agent Board 0.2.8

- In-game replies are no longer sent twice after a failed CLI turn or once
  the dispatch history fills up.
- Overlay actions report their own result, and a timeout says the action may
  still go through.
- Replies to remote hosts no longer block the overlay, and marking a remote
  session read now works.
- Much lower CPU use with many T3 threads, and far fewer disk writes while idle.

Offline gates and isolated native lifecycle checks passed. Real WoW, remote
host and live provider acceptance remain unverified.

Install:

```bash
curl -fsSL https://raw.githubusercontent.com/btsouth/agent-board/v0.2.8/install.sh | bash
```

Existing installs can run `agent-board update`. Reload WoW's UI after updating
the addon.

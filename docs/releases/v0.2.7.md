# Agent Board 0.2.7

- More reliable WoW detection, placement and start/stop handling.
- Automatic, manual and pause-until-exit visibility controls.
- Fixed T3-only updates, background message queues and disappearing approvals.
- Uncertain replies stay held instead of being sent twice.
- Remote sessions now appear in the live overlay.
- Explicit permissions for new T3 sessions and clearer runtime diagnostics.
- Less idle polling, fewer database reads and better provider recovery.

Offline gates, browser fixture checks and isolated native lifecycle checks
passed. Real WoW and live provider acceptance remain unverified.

Install:

```bash
curl -fsSL https://raw.githubusercontent.com/btsouth/agent-board/v0.2.7/install.sh | bash
```

Upgrade older managed installs, including T3-only 0.2.6:

```bash
curl -fsSL https://raw.githubusercontent.com/btsouth/agent-board/v0.2.7/install.sh | bash -s -- --update
```

Reload WoW's UI after updating the addon.

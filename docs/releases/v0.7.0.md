One-command setup for the Hermes WoW bridge on Linux.

- Finds your game and Hermes installation, installs the addon, and verifies the first snapshot.
- Starts the bridge automatically at login, with no terminal left open.
- Adds status, update and uninstall commands. Failed updates restore the previous installation.
- Improves first-run instructions and snapshot recovery guidance.

Requires an existing Hermes installation and Linux with a systemd user session, Python 3.10+, Git and curl. The addon ZIP alone does not provide the bridge.

Live setup, uninstall and reinstall passed on Linux. Offline gates cover update rollback and duplicate watchers. This remains a Classic beta preview for interface 16001; in-game controls and other clients are unverified.

# Agent Board 0.2.4

`agent-board demo --autoplay` records itself. Start your screen recorder, run
the command, and the board plays the whole story in about a minute:

1. The board opens as an agent works through its tool steps and streams a reply.
2. It switches to a session waiting for approval and presses Approve.
3. It types a reply into the composer and sends it, and the agent answers.
4. It collapses back to the badge.

Clicks and typing go through the real buttons and composer, so it looks like
someone using it. `--speed 1.5` makes it shorter. Autoplay only works while a
demo is running, so it can never touch real sessions.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/btsouth/agent-board/v0.2.4/install.sh | bash
```

Existing installs can run `agent-board update`.

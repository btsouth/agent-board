# Agent Board 0.2.5

`agent-board demo --autoplay` now plays the whole story in about 33 seconds,
short enough for a post: an agent works and streams its answer, a waiting
session gets approved, a reply is typed and answered, and the board collapses
to the badge. The manual `agent-board demo` keeps its normal pace.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/btsouth/agent-board/v0.2.5/install.sh | bash
```

Existing installs can run `agent-board update`.
